# {Dev}Lounge-FIAP ☕🚀

Bem-vindo à organização **{Dev}Lounge-FIAP**! Este é o nosso hub colaborativo focado no desenvolvimento de soluções robustas. Aqui centralizamos tanto os nossos projetos e desafios acadêmicos desenvolvidos na **FIAP** quanto as nossas iniciativas particulares e side-projects como grupo.

Nossa missão é transformar conceitos teóricos em código limpo, funcional e escalável, cobrindo desde pipelines de dados até simulações lógicas complexas.

---

## 🚀 Nossos Projetos em Destaque

Dividimos nossos repositórios entre soluções de impacto social e engenharia de software avançada. Conheça nossos principais ecossistemas:

### 🪐 Simulações e Sistemas Lógicos
*   **[intelligent-colony-system](https://github.com/DevLounge-FIAP/intelligent-colony-system)**
    *   *Descrição:* Sistema inteligente projetado para simulação, telemetria e monitoramento de parâmetros críticos em ambientes coloniais isolados.
*   **[mars-landing-management-system](https://github.com/DevLounge-FIAP/mars-landing-management-system)**
    *   *Descrição:* Simulador lógico baseado em Python para o gerenciamento de missões de pouso em Marte. Focado na otimização de recursos escassos, balanceamento de energia e tomada de decisão do módulo de pouso.

### 📊 Engenharia de Dados & Automação
*   **[ong-data-pipeline](https://github.com/DevLounge-FIAP/ong-data-pipeline)**
    *   *Descrição:* Pipeline automatizado de modernização de dados (ETL) desenvolvido como atividade de extensão para uma organização de bem-estar animal. Focado em centralização, tratamento e integridade de dados operacionais.

## 🛠️ Nosso Stack Tecnológico

Exploramos ferramentas modernas para garantir eficiência e performance no desenvolvimento:

*   **Linguagens de Programação:** Python, SQL
*   **Engenharia de Dados:** Pipelines de ETL, Modelagem Relacional (MySQL), Arquitetura Medallion
*   **Ambiente & Infraestrutura:** Git/GitHub, ambientes baseados em automação de scripts e Linux

---

## 📈 Boas Práticas do Grupo

Para manter a casa organizada e os repositórios saudáveis, seguimos alguns combinados fundamentais:

*   **Commits Semânticos:** Mensagens claras que explicam exatamente o que foi alterado.
*   **Code Review:** Pull Requests são revisados e testados antes do merge final nas branches principais.
*   **Documentação:** Todo repositório deve conter instruções claras de como rodar o ambiente localmente.
